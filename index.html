Agent Loop

Итеративный цикл: LLM думает → вызывает инструмент → получает результат → думает снова. До 10 итераций на задачу. Потоковый вывод в реальном времени.

Режим кодинга

Агент читает проект, пишет и правит файлы хирургически. Multi-edit, rename, diff, apply patch.

$ aios code "добавь валидацию в UserForm"

Git из коробки

Smart-commit генерирует осмысленные сообщения. Secret scanning не даст закоммитить API-ключи.

auto-commit secret scan branch protect

01

Клонируй и установи

Используем uv для молниеносной установки зависимостей.

git clone https://github.com/anomalyco/aios-cli.git cd aios-cli && uv venv && uv pip install -e .
02

Настрой провайдера

Локальный Ollama, облачный GPT или Gemini — одна команда.

aios doctor # проверка aios config --set-provider ollama # выбор
03

Работай

Чат, кодинг или полноценный TUI — выбирай свой стиль.

aios ask "объясни этот код" # quick aios chat # interactive aios code # coding agent aios tui # full UI
